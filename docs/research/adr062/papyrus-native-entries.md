# ADR-062: the Papyrus native entries in SkyrimSE 1.6.1170 (static read)

Read 2026-11-02 by the re-analyst for ADR-062 decision 2 (one hook per native through which a script changes
server-owned state). Everything below is a decompiler read (rule 2): every inferred behaviour is HYPOTHESIS until a
Frida trace or a lab run confirms it. No address or id below comes from memory (rule 1); the sources are named per
row. REA was down tonight; the read is pyghidra-mcp's on the sky-re project's program
`/SkyrimSE-1.6.1170.0.exe.unpacked.exe` (image base 0x140000000; addresses below are RVAs).

## Method

1. The registration string. Skyrim registers each Papyrus native from a per-class registrar that constructs a
   `BSScript::NF_util::NativeFunction` with the script name and the class name as string arguments. `search_strings`
   found the Papyrus names in a block around 0x14191xxxx to 0x14193xxxx ("PlaceActorAtMe" 0x1419307e0,
   "SetCurrentStageID" 0x141931cc0, "ForceRefTo" 0x14191d338, "GlobalVariable" 0x1419263b8, "Resurrect"
   0x14191a3d0, "ObjectReference" 0x14192c858). Some names are pooled with other literals and Ghidra had not typed
   them as strings: "AddItem" 0x1417d2c50 (also the console command's name, hence a second, data-side xref from the
   console command table at 0x141fdbab0), "Lock" 0x141766dfc, "Kill" 0x14191a344, "Stop" 0x14191d728; `read_bytes`
   confirmed each text.
2. The registrar. `list_xrefs` on a name string gives the registrar function; one per class:
   ObjectReference FUN_140a31ac0 (0xa31ac0, id 56246; 115 registrations), Actor FUN_1409eb9d0 (0x9eb9d0, id
   54784; 173 registrations), Quest FUN_140a47340 (0xa47340, id 56688; 24), ReferenceAlias FUN_140a035a0
   (0xa035a0, id 55292; 6), GlobalVariable FUN_140a21490 (0xa21490, id 55926; 2: GetValue and SetValue).
   PlaceActorAtMe is registered under ObjectReference, not Actor.
3. The callback. Each registration decompiles to `FUN_14143e0e0(obj, "Name", "Class", ...)` (the NativeFunction
   base constructor) followed by `obj[10] = callback` (the function pointer at NativeFunction+0x50, the same slot the
   fork's Hooks.cpp BindNativeMethod reads as `raw + 0x50`), or to a templated helper constructor
   (FUN_140a3b800, FUN_140a3b610, FUN_140a3b6a0, FUN_140a3b740, FUN_140a3bbe0, FUN_1409f3440, FUN_1409f3290,
   FUN_140a03cf0) that takes the callback as its fourth argument. The object then goes to the VM's vfunc at +0xC0
   (slot 0x18, BindNativeMethod, the slot Hooks.cpp HookVirtualMachineBind writes) and, for most natives, to vfunc
   +0xD0 with (class, name, 1) (HYPOTHESIS: SetCallableFromTasklets). A scratch parser over the two big registrars
   produced the name to callback table; the three pooled names were read by hand from the lines around their xrefs.
4. The body. Each callback was decompiled; where it builds a `SkyrimScript::*Functor` the functor's vtable was read
   with `read_bytes` and its slot 1 decompiled (slot 1 is `DelayFunctor::operator()`, CommonLibSSE-NG
   include/RE/D/DelayFunctor.h:35). Cross-references were followed one level down to the engine call.
5. The id. A scratch reverse lookup built on lab/addr.py's loader (versionlib-1-6-1170-0.bin, 428,461 entries) maps
   each RVA to its Address Library id; forward-checked with `just addr` on 19800, 37896, 14297, 53987 and 40488.
   CommonLibSSE-NG names come from lab/relids.tsv (the ids CommonLib binds) and the cited header or source lines.
6. Two callbacks are labels, not functions, in Ghidra (SetDestroyed 0xa44bf0, GlobalVariable.SetValue 0xa21440);
   they were disassembled instead. Both have Address Library ids.
7. Papyrus-level wrappers (not natives) were confirmed from the vanilla sources the SKSE download carries:
   lab/.cache/skse-1.6.1170/Data/Scripts/Source/Quest.psc, ObjectReference.psc, Actor.psc.

Calling convention (all rows): `R f(BSScript::IVirtualMachine* vm, StackID stackId, Self* self, args...)`, the long
form the engine's own natives use (the fork's Offsets.h PushActorAway has the same shape). Floats arrive in the
XMM register of their position (SetValue's value in xmm3, DamageObject's damage in xmm3) and show as `undefined4` in
the decompiler. A latent native returns through the VM's vfunc at +0x158 (HYPOTHESIS: ReturnFromLatent) when it
refuses or when its functor finishes.

Layout note: in this binary Actor's lifeState bits sit at +0xC8, currentProcess at +0xF8 and myKiller at +0x108,
each 8 bytes past the CommonLibSSE-NG SE offsets (ActorState.h:114, Actor.h:651, Actor.h:654); the fork's accessors
already handle that shift (memory: CommonLib runtime-data accessor).
