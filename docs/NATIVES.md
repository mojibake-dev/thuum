hand-maintained and preserved across regeneration. This file is the honest

Status meanings:
- implemented: runs on the server VM against server state.
- delegated: forwarded to the host client as a snippet; result recorded (R2).
- stub: no-op. Every stub needs a reason and a verb, or a "never" with a reason.
